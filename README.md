# MyClassroomUPM
Aplicación de escritorio en Java de la ETSISI (UPM) para gestionar aulas: los usuarios se registran con su cuenta UPM y, según su rol (alumno, PAS o PDI), dan de alta aulas, las consultan o se suscriben. No es funcional, ya que faltan archivos por falta de permisos de los integrantes que participaron en el código.
